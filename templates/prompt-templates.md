# プロンプトテンプレート集

AI分析・生成に使うプロンプトをバージョン管理します。  
勝ちパターンが見つかったら、テンプレートを追加・更新してください。

---

## 1. 構造分析プロンプト（v1.0）

### 用途
バズ動画を分析し、構造を抽出するときに使用。

### プロンプト

```
以下のショート動画について、5つの観点で構造分析をしてください。

【動画情報】
- プラットフォーム: {platform}
- 再生数: {views}
- 保存数: {saves}

【スクリプト/書き起こし】
{transcript}

【分析してほしい5つの観点】

1. 冒頭1秒で視聴者の手を止めている理由は何か
2. 視聴者が続きを見たくなる理由は何か（期待・疑問・違和感のどれが働いているか）
3. 感情が動くポイントはどこか（笑い・驚き・納得・感動）、それはどう作られているか
4. この動画の構造を抽象化するとどうなるか。自社商品「{product}」に置き換えるとどうなるか
5. そのまま真似ると危険な表面要素はどこか（キャラクター・構図・セリフ・演出・世界観）

【出力形式】
各観点について2〜3文で簡潔に。最後に「パターン分類」を1つ選んでください。
パターン候補: 違和感型 / Before After型 / 検証型 / あるある型 / 擬人化型 / 失敗回避型 / 逆張り型 / その他
```

## 2. 翻案プロンプト（v1.0）

### 用途
分析した構造を自社商品に翻案するときに使用。

### プロンプト

```
以下の構造をもとに、自社商品のショート動画案を3つ作成してください。

【抽象構造】
{abstract_structure}
例: 「ありえないキャラクターが、真剣に何かをしている違和感」

【自社商品情報】
- 商品名: {product_name}
- 商品カテゴリ: {category}
- ターゲット: {target}
- 訴求ポイント: {key_message}

【各案に含めてほしい要素】
1. タイトル（15文字以内）
2. 冒頭1秒の演出（何で手を止めるか）
3. 展開の概要（3〜5ステップ）
4. 商品の出し方（何秒目にどう出すか）
5. 想定する視聴者の反応（笑い/驚き/納得/共感）
6. 検証仮説（この動画で何を検証するか）

【注意】
- 元の参考動画の見た目をコピーしないこと
- ブランドイメージに合っていること
- 商品訴求が唐突でないこと
```

## 3. TopView用プロンプト（v1.0）

### 用途
TopView Video Agentに入力するプロンプト。

### プロンプト

```
{product_name}のショート動画を作成してください。

【構造】
- 冒頭: {opening_hook}
- 展開: {development}
- 商品登場: {product_appearance}
- 結末: {ending}

【トーン】
{tone}（例: 驚き→納得、違和感→笑い、共感→解決）

【テンポ】
- 全体尺: {duration}秒
- カット数: {cuts}カット目安
- 商品登場タイミング: {product_timing}秒目

【参考】
参考動画のリズム・テンポを参考にしつつ、見た目は別物にしてください。
```
