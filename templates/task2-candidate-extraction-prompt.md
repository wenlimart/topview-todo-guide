# Claude for Chrome用：Task2 候補動画抽出プロンプト

## 目的

このTikTok検索結果ページから、候補動画の情報を取得してください。

目的は、ショート動画の表面を真似るためではなく、反応が生まれる構造を分析するための候補動画を集めることです。

動画を楽しむことではなく、条件に合う候補を一覧化することが目的です。

## 取得件数

この検索結果ページから、条件に合う候補動画を最大5本取得してください。

ただし、条件に合うものが5本未満の場合は、無理に5本にしなくて構いません。

## 取得する情報

各候補について、以下を取得してください。

- search_query
- url
- caption（冒頭50文字程度）
- creator
- likes
- views（表示されていれば）
- posted_date
- hashtags（表示されていれば）

## 日付ルール

- TikTok上で年が表示されていない月日表示は、今年として `YYYY-MM-DD` に補完してください
- 年が表示されている場合は、その年を使ってください
- 日付はTikTokの表示仕様に基づいて補完してください
- 不明な場合は空欄にしてください

## likes / views の扱い

- likes は画面表示のままで構いません
  - 例：`55.3K`、`1.2M`、`826`
- views も表示されていれば画面表示のままで構いません
- views が表示されていなければ空欄にしてください

## 除外対象

以下に該当するものは除外してください。

- 広告
- photo投稿は原則として動画候補より優先度を下げてください。
  ただし、短期間で反応が強いもの、リスト型・手順型・比較型・保存されやすい構造が明確なものは、
  photo/スライド候補として残して構いません。
- 芸能人・有名人・スポーツ選手など特定人物依存
- アニメ・漫画・映画・ゲームなど既存IP依存
- ブランド名・商品名そのものが主役
- 炎上・事件・ニュース便乗
- ダンス・音源・顔芸・個人技だけで成立しているもの
- 表面の見た目を真似しないと成立しなさそうなもの
- 古くて反応が弱いもの

## 数値足切り

以下の基準で、古くて反応が弱い候補は除外してください。

- 投稿から30日超で、いいね数が2,000未満のものは除外
- 投稿から90日超で、いいね数が10,000未満のものは除外
- 投稿から180日超のものは、いいね数が大きいか、定番構造・派生元に見える場合のみ残す
- 構造が分かりやすくても、上記基準を満たさないものは除外してください

## 優先する候補

以下に該当するものを優先してください。

- いいね数が多いもの
- 投稿からの経過日数に対して反応速度が高そうなもの
- 検索一覧画面で明らかに反応が強そうなもの
- 便利ワザ、知らないと損、比較、失敗回避、手順化、Before/Afterの型が見えるもの
- 構造を別テーマに翻案できそうなもの
- Topviewで別素材・別文脈に置き換えられそうなもの
- 顔出しや特殊撮影に依存しないもの

## 操作制限

以下の操作はしないでください。

- ログイン操作
- フォロー
- いいね
- 保存
- コメント
- 投稿
- 設定変更
- 不要な動画再生
- 外部サイトへの遷移

ページの読み取りと候補情報の抽出だけ行ってください。

## 出力形式

Googleスプレッドシートに貼り付けやすいTSV形式で出してください。

説明・考察・補足は不要です。TSVのみ出力してください。

列は必ず以下の順番にしてください。

search_query	url	caption	creator	likes	views	posted_date	hashtags

## 出力例

search_query	url	caption	creator	likes	views	posted_date	hashtags
[検索クエリ]	[動画URL]	[キャプション冒頭]	[投稿者名]	[いいね数]	[再生数]	[投稿日]	[ハッシュタグ]

## 注意

- 取得できなかった項目は空欄にしてください
- 同じ投稿者の動画が複数出た場合は、最も反応が強い1本だけ残してください
- 条件に合わない候補を無理に含めないでください
- 出力はTSVのみ。説明文、箇条書き、選定理由、補足メモは不要です
