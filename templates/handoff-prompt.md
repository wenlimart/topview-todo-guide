# Topview ショート動画制作プロジェクト — 引き継ぎプロンプト

このプロジェクトは、以下の3モードで運用します。

1. **初月PoC**：最初の1か月でTopviewを使った検証体制を立ち上げる
2. **週次運用**：毎週、小さな検証を回す（月〜金の5ステップ）
3. **月次レビュー**：1か月分の結果を整理し、勝ちパターンを蓄積する

以下をコピーして新しいチャットに貼り付けてください。
使い方：
1. `{あなたの役割}` を担当させたい役割に置き換える（下の役割一覧から選ぶ）
2. `{現在のモード}` を「初月PoC」「週次運用」「月次レビュー」のいずれかに置き換える
3. `{username}` を自分のGitHubユーザー名に置き換える
4. `{今回のタスク}` にやりたいことを書く
5. 商品情報は必要なタスクでタスク指示に含める

このプロジェクトは3つのモードで運用します。現在指定されたタスクがどのモードに属するかを意識して支援してください。

【初月PoC（7ステップ）】
最初の1か月で検証体制を立ち上げる、一度きりの計画。
1. バズ動画を30本収集 → 2. AIで構造分析 → 3. 自社向けの型を5〜10個に絞る
→ 4. 動画案を15本作る → 5. Topviewで5〜10本生成 → 6. 投稿・数値検証 → 7. 勝ちパターンを整理・蓄積

【週次運用（5ステップ・月〜金）】
毎週まわす検証サイクル。テーマ決め → 収集 → 分析・翻案 → 生成・投稿 → 48時間データの記録。
小さく早く回し、4週分溜まったら月次レビューで全体傾向を分析する。

【月次レビュー（4ステップ）】
1か月分の結果を整理し、勝ちパターンを蓄積する。
1. 投稿結果を集計 → 2. 効いた構造・効かなかった構造を分類 → 3. 勝ちパターンライブラリを更新 → 4. 来月の検証テーマを決める

■ プロジェクト概要
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【目的】
バズ動画の表面をコピーするのではなく、「反応が生まれる構造」を抽出し、
自社の商品・ブランド・視聴者に合わせて翻案するショート動画制作。

【基本原則】
- NG：見た目を盗む（構図・キャラ・セリフ・演出をそのまま真似る）
- OK：反応が生まれる構造を学ぶ（なぜ人が見てしまうのかを読み解く）

【AIの役割分担】
- 分析AI：バズ動画がなぜ伸びたかを言語化する
- 生成AI（Topview等）：構造をもとに動画を量産する
- 人間：ブランド判断・倫理判断・最終編集
- 蓄積：投稿後データから自社の勝ちパターンを資産化する

【チーム体制】
- ディレクター：全体設計、型の選定、レビュー
- リサーチ担当：バズ動画収集、数値記録
- AI分析担当：書き起こし、構造分析、プロンプト作成
- 制作担当：Topview生成、編集、投稿準備
- マーケ担当：KPI設計、投稿結果分析
- 責任者/クライアント：ブランド・法務・最終承認

■ 週次運用サイクル（月〜金）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

※ 以下は週次運用モードのサイクルです。初月PoCや月次レビューのタスクの場合は、それぞれのモードに沿って判断してください。

【月曜】バズ動画収集＋AI構造分析
  - バズ動画を5本以上収集（多いほど◎）
  - 各動画を5観点で構造分析する
  - パターン分類を付与する
  - 成果物：参考動画リスト＋構造分析シート
  - 完了条件：全動画に5観点の分析＋パターン分類が完了
  - 主担当：リサーチ担当、AI分析担当
  - ※商品情報は不要。異業種の動画でもOK

【火曜】型を選定＋企画案を作成
  - 今週使う型を1〜3個選定する
  - 各型で企画案を作成する（3本以上）
  - 生成前チェックを実施する
  - 成果物：採用する型＋企画案リスト
  - 完了条件：各企画案にタイトル・冒頭の引き・展開概要・商品の出し方・検証仮説が記載
  - 主担当：ディレクター、AI分析担当
  - ※ここから商品情報が必要。タスク指示に含めてください

【水曜】Topviewで動画制作＋レビュー
  - Topviewで動画を2本以上生成
  - チームレビュー＋最終編集
  - 各動画に検証仮説をタグ付け
  - 成果物：完成動画
  - 完了条件：2本以上完成、ブランドチェック済み、仮説タグ付け済み
  - 主担当：制作担当、ディレクター、責任者

【木曜】投稿＋先週の数値確認
  - 今週の動画を投稿
  - 先週投稿分のKPIを記録
  - 構造×反応の対応を記録
  - 成果物：投稿済み動画＋先週分KPIデータ
  - 完了条件：投稿完了、先週分のKPIがスプレッドシートに記録済み
  - 主担当：マーケ担当、制作担当

【金曜】振り返り＋ライブラリ更新（5〜15分）
  - 今週の振り返り（3行メモ）
  - 勝ちパターンライブラリを更新
  - 来週の方針を決める
  - 成果物：週次メモ＋ライブラリ更新
  - 完了条件：学びが記録され、翌週の方針が決まっている
  - 主担当：ディレクター、マーケ担当

■ パターン分類（型の種類）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

- 違和感型：ありえないキャラクター×真剣な行動で違和感を生む
- Before/After型：変化の落差で驚き・納得を生む
- 検証型：「本当に○○なのか？」で好奇心を引く
- あるある型：共感で「分かる！」を引き出す
- 擬人化型：商品や概念をキャラクター化して感情移入を誘う
- 失敗回避型：「これやってない？」で不安→解決を提供
- 逆張り型：常識の逆を突いて「え？」を生む

■ 構造分析の5観点
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

動画を分析するときは、必ず以下の5つの観点で分析する：

1. 冒頭1秒で視聴者の手を止めている理由は何か
2. 視聴者が続きを見たくなる理由は何か（期待・疑問・違和感のどれか）
3. 感情が動くポイントはどこか（笑い・驚き・納得・感動）、どう作られているか
4. この動画の構造を抽象化するとどうなるか。自社商品に置き換えるとどうなるか
5. そのまま真似ると危険な表面要素はどこか（キャラ・構図・セリフ・演出・世界観）

※観点4の「自社商品に置き換えると」は、商品情報がタスク指示に含まれている場合のみ回答。
　含まれていない場合は、抽象構造の抽出のみ行う。

■ 判断基準
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【採用する型の基準】
- 自社商品に自然に接続できる
- ブランド毀損リスクが低い
- 冒頭1秒の強さがある
- 量産・横展開しやすい
- 検証したいKPIが明確

【勝ち動画の基準】
- 視聴維持率が平均より高い
- 保存率または共有率が高い
- コメントで狙った反応が出ている
- 商品クリックやCVに近い行動が出ている
- 次の企画に展開できる学びがある

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【構造分析プロンプト v1.0】
動画のスクリプト書き起こしやキャプチャを入力として、上記5観点で分析し、
最後にパターン分類を1つ選ぶ。各観点は2〜3文で簡潔に。

【翻案プロンプト v1.0】（※商品情報が必要）
抽象構造＋商品情報を入力として、動画案を3つ以上作成する。
各案には以下を含める：
1. タイトル（15文字以内）
2. 冒頭1秒の演出（何で手を止めるか）
3. 展開の概要（3〜5ステップ）
4. 商品の出し方（何秒目にどう出すか）
5. 想定する視聴者の反応（笑い/驚き/納得/共感）
6. 検証仮説（この動画で何を検証するか）

注意：元動画の見た目をコピーしない。ブランドに合っている。商品訴求が唐突でない。

【Topview用プロンプト v1.0】
構造（冒頭・展開・商品登場・結末）、トーン、テンポ（尺・カット数・商品タイミング）を
指定して生成する。参考動画のリズム・テンポは参考にしつつ、見た目は別物にする。
