# 🎬 TopView ショート動画制作 — 初月実行プラン

YouTubeチャンネル「ショート動画の構造調査」用の、TopViewを使った初月PoC実行管理ツールです。

AI時代のショート動画制作フレームワークに基づき、バズ動画の表面をコピーするのではなく、反応が生まれる構造を学び、自社の文脈に翻案するための7ステップ実行プランです。

## 概要

バズ動画の**表面をコピーする**のではなく、**反応が生まれる構造を学び、自社の文脈に翻案する**。  
このフレームワークを初月で検証するための7ステップ実行プランです。

## 運用サイクル（7ステップ）

| # | フェーズ | 週 | 成果物 |
|---|---------|---|-------|
| 1 | バズ動画を30本収集 | 1週目前半 | 参考動画リスト |
| 2 | AIで構造分析 | 1週目後半 | 構造分析シート30件 |
| 3 | 自社向けの型を選定 | 2週目前半 | 勝ちパターン候補5〜10個 |
| 4 | 動画案を作成 | 2週目後半 | 企画案15本 |
| 5 | TopViewで動画制作 | 3週目 | テスト動画5〜10本 |
| 6 | 投稿・数値検証 | 4週目 | 投稿結果レポート |
| 7 | 勝ちパターン整理 | 月末 | 勝ちパターンライブラリ v1 |

## チーム体制

| 役割 | 担当 |
|-----|------|
| ディレクター | 全体設計、型の選定、レビュー |
| リサーチ担当 | バズ動画収集、数値記録 |
| AI分析担当 | 書き起こし、構造分析、プロンプト作成 |
| 制作担当 | TopView生成、編集、投稿準備 |
| マーケ担当 | KPI設計、投稿結果分析 |
| 責任者/クライアント | ブランド・法務・最終承認 |

## セットアップ

```bash
# 依存関係のインストール
npm install

# 開発サーバー起動
npm run dev

# ビルド
npm run build
```

## GitHub Pages 公開手順

1. このリポジトリを GitHub にプッシュ
2. Settings → Pages → Source を `GitHub Actions` に設定
3. `main` ブランチに push すると自動デプロイ
4. `https://<username>.github.io/topview-todo-guide/` で公開
