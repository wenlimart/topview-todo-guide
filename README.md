# 🎬 Topview ショート動画制作 — 運用Todoガイド

AI時代のショート動画制作フレームワークに基づく、Topviewを使ったバズ動画の構造分析・生成・検証を回すためのTodoガイドです。

## 概要

バズ動画の **表面をコピーする** のではなく、**反応が生まれる構造を学び、自社の文脈に翻案する**。
このフレームワークを **初月PoC → 週次運用 → 月次レビュー** の3つの運用モードで回し、勝ちパターンを高速に蓄積します。

## ⚠️ 公開リポジトリに置かない情報

このリポジトリは公開を前提としているため、以下の情報は**コミットしないでください**。これらは別途、社内ドキュメントやスプレッドシートで管理してください。

- 実際の参考動画URL・スクリーンショット・書き起こしテキスト
- 投稿済み動画の数値（再生数・視聴維持率・保存数・CV等）
- クライアント名・商品名・未公開企画の詳細
- 個別の勝ちパターンライブラリの中身（命名は共有しても、テンプレート本文は社内のみ）
- 個人を特定できる情報やSNSアカウント

このリポジトリで管理するのは **運用フレームワーク・タスク手順・テンプレート骨子のみ** です。

## 3つの運用モード

アプリ上部のタブで以下の3モードを切り替えながら使います。

### 🚀 初月PoC（7ステップ）
最初の1か月でTopviewを使った検証体制を立ち上げるための、一度きりの立ち上げ計画です。

1. バズ動画を30本収集する
2. AIで構造分析する
3. 自社向けの型を5〜10個に絞る
4. 動画案を15本作る
5. Topviewで5〜10本生成する
6. 投稿・数値検証する
7. 勝ちパターンを整理・蓄積する

完了後はバッジが表示され、以降の運用は週次運用モードへ移行します。タブは常に表示されるので、後から見返せます。

### 🔄 週次運用（月〜金 5ステップ）
毎週、小さな検証サイクルを回すための実行Todoです。

| 曜日 | やること | 成果物 |
| --- | --- | --- |
| 🎯 月 | 今週のテーマ決め＋バズ動画を収集 | 検証テーマ＋参考動画リスト |
| 🔬 火 | 構造を分析・翻案する | 分析メモ＋企画案 |
| 🎬 水 | Topviewで生成＋レビュー | 完成動画2本〜 |
| 📤 木 | 投稿＋先週分のKPI記録 | 投稿動画＋KPIデータ |
| 📊 金 | 48時間データを記録＋振り返り | 検証メモ＋ライブラリ更新 |

← → ボタンで過去・未来の週に切り替えられます。週ごとに進捗・成果物リンク・メモを独立して保存します。

### 📈 月次レビュー（4ステップ）
1か月分の結果を整理し、勝ちパターンを蓄積するための振り返りTodoです。

1. 投稿結果を集計する
2. 効いた構造・効かなかった構造を分類する
3. 勝ちパターンライブラリを更新する
4. 来月の検証テーマを決める

月末〜翌月初に実施し、決定事項は週次運用モードの第1週テーマとして引き継ぎます。

## チーム体制

| 役割 | 担当 |
| --- | --- |
| ディレクター | 全体設計、型の選定、レビュー |
| リサーチ担当 | バズ動画収集、数値記録 |
| AI分析担当 | 書き起こし、構造分析、プロンプト作成 |

## 機能

- **3モード切り替え**: 初月PoC / 週次運用 / 月次レビュー をタブで切り替え
- **タブ進捗表示**: 各モードの完了タスク数を `3/25` 形式で常時表示
- **週切り替え**（週次運用のみ）: ← → で過去・未来の週に移動、週ごとに進捗を独立管理
- **ステータス管理**: 未着手 → 進行中 → 完了 の3段階
- **担当ロール表示**: 各タスクに担当者バッジ
- **完了条件**: 各フェーズに明確なゴール定義
- **判断基準**: 型の選定・勝ち判定の基準を内蔵
- **成果物リンク**: モード別・フェーズ別に保存
- **モード別メモ**: 自由記述の振り返りエリア（モードごと、週次は週ごと）
- **完了済みバッジ**: 初月PoC全完了時にバッジを表示（タブは残るので後から見返せる）
- **モード別リセット**: 表示中のモード（週次は表示中の週）だけをリセット
- **自動保存**: localStorage にモード別・週別に保存

## localStorage キー設計

| 項目 | キー例 |
| --- | --- |
| 初月PoC ステータス | `topviewTodoStatus_initial` |
| 初月PoC リンク | `topviewDeliverableLinks_initial` |
| 初月PoC 展開状態 | `topviewExpanded_initial` |
| 初月PoC メモ | `topviewNotes_initial` |
| 週次運用 ステータス | `topviewTodoStatus_weekly_2026-05-11` |
| 週次運用 リンク | `topviewDeliverableLinks_weekly_2026-05-11` |
| 週次運用 展開状態 | `topviewExpanded_weekly_2026-05-11` |
| 週次運用 メモ | `topviewNotes_weekly_2026-05-11` |
| 月次レビュー ステータス | `topviewTodoStatus_monthly` |
| 月次レビュー リンク | `topviewDeliverableLinks_monthly` |
| 月次レビュー 展開状態 | `topviewExpanded_monthly` |
| 月次レビュー メモ | `topviewNotes_monthly` |
| 現在モード | `topviewCurrentMode` |
| 現在の週（週次用） | `topviewCurrentWeek` |
| ロール表示トグル | `topviewShowRoles` |

週次運用モードのキーは末尾に週ID（`YYYY-MM-DD` 形式・月曜起点・ローカルタイムゾーン基準）が付きます。

旧バージョン（`topview_weekly_state`）からのデータは初回起動時に自動的に新キー（週次運用モード）へ移行されます。
