# 🎬 TopView ショート動画制作 — 週次サイクル

AI時代のショート動画制作フレームワークに基づく、週次サイクルの実行管理ツールです。

## 概要

バズ動画の**表面をコピーする**のではなく、**反応が生まれる構造を学び、自社の文脈に翻案する**。  
このフレームワークを毎週のサイクルで回し、勝ちパターンを高速に蓄積します。

## 週次サイクル（月〜金）

| 曜日 | やること | 成果物 | 目安数量 |
|------|---------|-------|---------|
| 🔍 月 | バズ動画収集＋AI構造分析 | 参考動画リスト＋分析シート | 5本〜（多いほど◎） |
| ✏️ 火 | 型を選定＋企画案作成 | 採用する型＋企画案リスト | 型1〜3個、企画3本〜 |
| 🎬 水 | TopViewで制作＋レビュー | 完成動画 | 2本〜 |
| 📤 木 | 投稿＋先週の数値確認 | 投稿済み動画＋KPIデータ | — |
| 📊 金 | 振り返り＋ライブラリ更新 | 週次メモ＋ライブラリ更新 | 5〜15分 |

> 数量は最低ラインです。多いほど学習データが増え、勝ちパターンの発見が早くなります。

## チーム体制

| 役割 | 担当 |
|-----|------|
| ディレクター | 全体設計、型の選定、レビュー |
| リサーチ担当 | バズ動画収集、数値記録 |
| AI分析担当 | 書き起こし、構造分析、プロンプト作成 |
| 制作担当 | TopView生成、編集、投稿準備 |
| マーケ担当 | KPI設計、投稿結果分析 |
| 責任者/クライアント | ブランド・法務・最終承認 |

## セットアップ

```bash
npm install
npm run dev     # 開発サーバー
npm run build   # ビルド
```

## GitHub Pages 公開手順

1. GitHub にプッシュ
2. Settings → Pages → Source を `GitHub Actions` に設定
3. `main` に push すると自動デプロイ
4. `https://<username>.github.io/topview-todo-guide/`

## 機能

- **週切り替え**: ← → で過去・未来の週に移動、週ごとに進捗を独立管理
- **ステータス管理**: 未着手 → 進行中 → 完了の3段階
- **担当ロール表示**: 各タスクに担当者バッジ
- **完了条件**: 各フェーズに明確なゴール定義
- **判断基準**: 型の選定・勝ち判定の基準を内蔵
- **成果物リンク**: スプレッドシートやNotionへの直リンク
- **週次メモ**: 自由記述の振り返りエリア
- **自動保存**: localStorage で週ごとに進捗を保持
